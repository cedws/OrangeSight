# OrangeSight

OrangeSight is a native Hacker News reader for iPhone and iPad. Browse stories
and threads, search Hacker News, and sign in to vote, comment, and submit
stories.

Open `OrangeSight.xcodeproj` in Xcode and run the `OrangeSight` scheme on an
iOS 26 or later simulator.

[GitHub Actions](https://github.com/cedws/OrangeSight/actions/workflows/ios.yml)
builds an unsigned iOS release archive.
